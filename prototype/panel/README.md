# 油猴面板 UI 原型

**这是一次性代码，不是生产实现。** 目的是让你翻看三个结构不同的面板设计，挑一个（或从各取零件），然后把其余丢掉。

## 怎么跑

双击 `panel/index.html`，或者跑：

```
node prototype/panel/verify.mjs          # 顺带生成 shots/ 下的截图
```

浏览器直接开（无需服务器、无构建、无依赖）：

```
file:///<仓库绝对路径>/prototype/panel/index.html?variant=A
```

## 三个变体

用 `?variant=` 切换，或点页面底部那条切换栏（它不是被评估的设计，是原型的骨架）：

| 键 | 名字 | 结构骨架 |
|---|---|---|
| `A` | 左侧导航 · 工作台式 | **竖向持久导航栏 + 右侧主区**，像一个小工作台窗口（460×640），日志是底部可上滑抽屉 |
| `B` | 横向标签 · 卡片流 | **横向 MD3 Tabs + 卡片流**，宽而扁的底部面板（约 68vw × 52vh），日志是卡片内联 accordion |
| `C` | 悬浮球 · 层级下钻 | **安静的悬浮球 → 模态 Dialog**，内部两级下钻（环节网格 → 环节详情），日志是底部隔板 |

底部切换栏还有三个按钮：`主题：浅/深/跟随`、`收起态`（触发当前变体的收起/展开）、`试日志`（往当前变体打一条演示日志）。

键盘 `←` `→` 也可切换变体（在输入框里不拦截）。

## 已落实的设计要求

- **MD3 风格**：`tokens.css` 是共享的 MD3 token 层——完整的光/暗两套颜色角色、高程阴影、形状档位、字阶、动效时长。三个变体只用变量，所以主题切换自动生效。
- **各环节分开**：T型账 / 明细账 / 日记账 / 科目汇总表 / 总账 / 会计报表 各自独立操作。前两个已接入真实数据，后四个标「待接入」。
- **只用教师答案**：三个变体里都不存在「学生答案」入口。页面文案一律写「数据源：教师答案」。
- **兜底快照**：老师答案若对该账号未开放，回落到仓库内置快照（`data/teacher-answer/detail-ledger.json`，2026-10-13 抓取）。
  三个变体都用一个**可点开关**在两种数据源状态间切换：
  - 默认 **primary**：`教师答案 · 实时`（正常路径，`--md-tertiary-container` 语义色）
  - 切到 **fallback**：`教师答案未开放 · 使用仓库内置快照（2026-10-13）`（`--md-warn-container` 警示色，且面板内相关文案同步变化）
  默认落在 primary 是刻意的：兜底态是异常路径，默认显示它会让人误以为系统坏了；开关一点即切，便于对比。
- **深色模式**：`data-theme="dark"` 或系统偏好都支持。
- **收起态不显眼**：三个变体各自的收起态都走低调路线——A 收成细长竖向导轨、B 收成右下角 32px 半透明状态条、C 收成半透明小悬浮球（opacity 0.62）。

## 验收

`node prototype/panel/verify.mjs` 会逐变体 × 明/暗两主题检查并截图，断言四件事：

1. 变体挂载成功且尺寸正确
2. **零控制台错误**
3. **不出现「学生答案」字样**
4. 数据源默认是「实时」态，且开关能切到「仓库快照」兜底态

最近一次结果：三个变体 × 两主题全部通过，`失败项：无`。截图在 `shots/`，机读结果在 `verify-report.json`。

## 数据来源

`fixtures.js` 是真实数据快照（只读），从 `.scratch/voucher2t-mxz/evidence/ans-full.json` 抽取：

| 项 | 数量 |
|---|---|
| 明细账应登账页 | 173 |
| 明细账簿（按一级科目） | 55 |
| 明细账逐笔行 | 417 |
| T 型账科目 | 45 |
| 记账凭证 | 103 |

⚠ **单位有两套，混用会差 100 倍**（`fixtures.js` 顶部有注释）：

| 数据 | 单位 | 处理 |
|---|---|---|
| `FX.sample[*].d/.l/.bal` | **分** | 显示前 ÷100（732800 → 7,328.00） |
| `FX.taccounts[].d/.l` | **元** | 直接格式化（15232 → 15,232.00） |

`FX.books[k][].rows` 是**行数**（数字）而非行数组，Σ = 417 = `FX.detailEntryTotal`。

## 接口契约

变体通过全局注册表登记，宿主页负责挂载、定位与主题：

```js
window.VP = window.VP || {};
VP.register('A', '左侧导航 · 工作台式', {
  mount(host, ctx) {
    // host: 已插入文档的 <div class="vp-root">，你自己往里面渲染
    // ctx.fx    : 夹具数据（window.FX）
    // ctx.api.log(msg, kind)      : 打日志，kind = info|ok|warn|err
    // ctx.api.setState({busy:bool}): 更新宿主状态
    return { unmount() {}, toggle() {} };   // toggle 可选，会被「收起态」按钮调用
  }
});
```
