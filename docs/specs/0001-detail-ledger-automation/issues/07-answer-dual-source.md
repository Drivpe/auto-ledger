# 07 — 双源答案抽取与归一化

**What to build:** 脚本拿到明细账的登账依据：**实时教师答案优先，取不到就落到仓库内置兜底快照**，两种来源喂给同一个归一化结果，消费方看不出区别。面板上能读出当前用的是哪一种。抓取支持断点续抓。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 取数入口按科目逐次查询教师答案（`SXID=0`，与 T 型账教师答案同源机制）
- [ ] 实时答案拿不到时自动落到仓库内置兜底快照，这一环不依赖老师开权限的动作
- [ ] 两种来源归一化成同一结构，消费代码不分叉（同一套解析器吃两种来源）
- [ ] 面板能读出当前数据源是「实时」还是「仓库快照」，并有状态开关可对比两态
- [ ] 断点续抓：中途停止后重跑不重复抓已拿到的科目
- [ ] 只读抓取沿用既有并发（凭证抓取的多路并发），不新开写路径
- [ ] 断言：数据源失败时**不会**退化成空数据交给下游（空数据当成结果会叠写）

## Comments

术语纪律：面板只认教师答案，「学生答案」在明细账链路上没有入口，界面上不出现这个词；兜底快照与「学生答案」不能混用。
