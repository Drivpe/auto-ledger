# 11 — 画月结线与年结线

**What to build:** 账页上那两条红线由脚本画出来。做完之后，有内容的科目六类结构行齐备，账页形态与老师答案一致。

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] 月结线与年结线作为**真实数据行**插入（行类 `8` 与 `9`），不是纯样式
- [ ] 画线前先把该行的**月与日**填好，不被平台以「"月"输入不能为空」拒绝
- [ ] 年结线若被平台以「上月未结账，不可输入下月记录」拒绝，按闸门结论决定本月是否画，并把结论写进日志与工单
- [ ] 结线行的摘要与行类标识按答案（`------------` 与 `=============`）
- [ ] 被拒的科目单独报出，本轮不静默跳过
- [ ] 断言：结线行的行类标识与月日字段在请求体里都非空

## Comments

一月任务是否需要年结线由闸门工单登记，本张按结论执行，不用推测填充。
