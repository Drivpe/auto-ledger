# 09 — 一个一级科目一本账簿 + 逐个建账页

**What to build:** 脚本按一级科目把账簿开出来，再把该科目下应登的账页一个个建好。做完这一步，平台账簿列表里出现 55 本账簿、明细账目录里出现 173 个账页，且每本只开活页三栏式、每个账页名称就是科目名。

**Blocked by:** 06, 07, 01

**Status:** ready-for-agent

- [ ] 账簿按**一个一级科目一本**组织，落账 55 本；组织口径来自答案快照的科目集合，不照抄答案（答案不带账簿结构）
- [ ] 账簿类别只开 `(活页)三栏式明细账`（平台该下拉的 value = `5`）；数量金额式与多栏式本轮不碰
- [ ] 账页集合 = 「有期初余额」∪「本期凭证触及」= 173；**无期初且无发生额的 133 个科目不建账页**
- [ ] 账页名称显式提交（平台不自动取科目名），名称即科目名
- [ ] 记账页走账簿开设接口的建账页提交段落，开账簿走开账簿提交段落；「账簿启用确认」就是同一张表改写提交段落，不是独立接口
- [ ] 55 本账簿各自唯一命名（重名是否被拒的结论取自已闭合的闸门）
- [ ] 断言请求体里提交段落标识与必填字段正确，**尤其账页名称被显式提交**
- [ ] 串行推进、有进度、可中断；进度显示当前第几本账簿、第几个账页

## Comments

「一本账簿能否容多账页」是这张的地基，闸门工单闭合前不得以推测填充该结论。平台的「自动建账簿」按钮本轮不用。
