# 14 — 面板按环节分区、收起态、深色模式

**What to build:** 面板从「一条长列表」变成**按环节分区**的形态：T型账 / 明细账 / 日记账 / 科目汇总表 / 总账 / 会计报表 各自独立，未接入的环节明确标记，明细账那组操作与 T 型账并列而不混淆。一屏说清状态，收起时低调不挡页面，深色模式可用。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 六个环节各自独立呈现，未接入的环节明确标出「尚未接入」，不让人去点一个还不工作的东西
- [ ] 明细账那一组操作与 T 型账并列；清除是其中语义危险的那个按钮，与正向操作长得不一样
- [ ] 面板上呈现当前数据源（实时 / 仓库快照）并留下可点的状态开关以便对比两态
- [ ] 界面上**不出现「学生答案」字样**（明细账链路整体弃用学生答案），断言可见文字里不含该词
- [ ] 文案以「一屏说清状态」为准：不写说明段落、不写警示区块、金额不保留无意义的小数尾
- [ ] 一键收起，收起态低调，不遮挡平台页面
- [ ] 完整支持深色模式
- [ ] 沿用既有的面板验收脚本形态：逐变体 × 明暗两主题截图并断言（挂载成功、零控制台错误、不出现「学生答案」字样、默认实时态、兜底态可达）
- [ ] 面板骨架的视觉形态按用户已选定的原型折进实现（竖向导航 / 横向标签 / 悬浮下钻三选一）

## Comments

面板骨架是一次独立的视觉决策，其选择不改变本 spec 中的任何行为契约。三个原型已在 `prototype/panel/` 按本轮要求改到位并验收通过。
