# 04 — 兜底快照的数据契约

**What to build:** 仓库内置的明细账教师答案快照可以被无条件信任：它与实时答案**结构同构**（同一套解析器吃两种来源），单位一致、六类行类齐备、自带 schema 标识与抓取时间与覆盖统计，且**逐字节不含学号、姓名、密码、会话标识**。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 快照自带 schema 标识、抓取时间、覆盖统计（请求数 / 实取数 / 非空数 / 空数 / 失败集）
- [ ] 断言快照与实时答案在字段名、行类、方向取值、金额单位上同构；消费代码不分叉
- [ ] 断言六类结构行齐备（年初 / 月汇 / 月结线 / 年累 / 年结线 各等于非空科目数），逐笔行总数与实测一致
- [ ] 断言金额单位是「分」，贷方字段语义是 `lend`
- [ ] 逐字节扫描断言：快照全文不含学号、姓名、密码、会话标识（含各类常见编码形态）
- [ ] 兜底快照与「学生答案」在数据与术语上都分开，断言两类数据不会被混用

## Comments

这是纯数据契约测试，与传输缝并列，不依赖任何网络与浏览器。spec 明确：兜底快照**不是**学生答案。
