# 05 — 账页状态解析与请求体构造

**What to build:** 脚本能读懂一张明细账账页的当前状态，并能构造出「把这批行写进去 / 画这条结线」的请求体。解析要覆盖已存行、待填行、空账页、含结线行四种形态；请求体要按平台的字段名与单位来，不能靠猜。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 解析已存行与待填行两种字段形态（已存行无后缀、待填行 `_i` 后缀），并断言整页提交后能重新解析出新状态
- [ ] 解析空账页（无任何已存行）与含结线行的账页，断言解析出的行集与行序
- [ ] 请求体金额一律按**分**构造（平台上 `balance=732800` 即 7328.00 元）
- [ ] 贷方字段名是 `lend`，方向字段 `in_debit_lend` 取 `0` 平 / `1` 借 / `-1` 贷
- [ ] 每一行带正确的凭证种类与行类标识（月初 / 年初 / 记收付汇 / 月汇 / 月结线 / 年累 / 年结线 / 年结）
- [ ] 断言「余额不为 0 时方向不能为平」这类平台必填约束在构造阶段就被满足，不是提交后被拒

## Comments

spec 的 Testing Decisions 点名本张要在传输缝上喂既有实测页面夹具（已存行 / 待填行 / 空账页 / 含结线行），断言解析出的行集与字段。字段名陷阱（`lend` 而非 `credit`）来自 `.scratch/voucher2t-mxz/ALIGNMENT.md` 的实测记录。
