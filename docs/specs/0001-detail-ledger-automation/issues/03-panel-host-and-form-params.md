# 03 — 面板宿主收窄与表单提交对象参数化

**What to build:** 面板挂载到真正的内容框架上（进入明细账环节时面板也要出现，且不挂在错误层级）；表单提交函数的作用对象从写死改成参数，使明细账页的表单能用同一套提交设施提交。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 面板宿主判定收窄到真正的内容框架；在明细账环节的账页内容页上面板能正常挂载
- [ ] 收窄之后 T 型账页上的面板仍然挂载成功（这是本张最大的回归风险，必须有断言）
- [ ] 表单提交函数的作用对象提成参数，明细账页表单与 T 型账页表单走同一个提交设施
- [ ] 提交后的等待判据沿用既有口径（等已保存行数真的增加），不靠前端记住状态
- [ ] 离线 harness 上可断言：给定两套不同框架结构的页面夹具，面板各挂到预期的那一层

## Comments

既有风险记录：面板宿主与回填目标**恰好是同一个框架**，这一重合是「脚本导航自己」风险的来源，收窄时不得把它变成两处不同的推断逻辑。
