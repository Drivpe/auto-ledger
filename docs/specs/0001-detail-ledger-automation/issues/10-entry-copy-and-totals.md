# 10 — 逐笔抄录 + 本月合计 + 本年累计落账

**What to build:** 一个科目的账页被照答案原样写满：期初、逐笔分录、本月合计、本年累计。写完读回核对行数，行数与答案对不上就报出来。这一张是「照抄」这件事的主体。

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 六类行按固定行序落账：`年初 → 逐笔* → 月汇 → 月结线 → 年累 → 年结线`
- [ ] 期初余额照答案的「年初 / 上年结转」原样落进去，金额按分
- [ ] 逐笔分录八列全抄：日期、凭证字、号数、摘要、借、贷、方向、余额
- [ ] **凭证号取自教师答案的平台真实编号**，不重算；科目 1001 末笔必须是 `记62` 而不是重排的 `记63`
- [ ] 摘要照答案抄，不另找摘要来源（答案自带逐笔摘要）
- [ ] 余额列照答案填，不留给平台自算
- [ ] 「本月合计」按答案金额落账
- [ ] 抄完**读回核对**：平台侧行数 / 关键字段与计划一致才算这一科目完成，不一致单独报出
- [ ] 每次整页提交后重新解析页面状态，不靠前端记住（已提交行与待填行是两种字段形态）
- [ ] 进度显示当前第几个账页、第几行

## Comments

「照抄」是本轮最重的口径变更：明细账不再由凭证归集计算，既有三重锁只继续服务 T 型账那一环；明细账侧校验改为「照抄过程自身可信 + 抄完读回核对行数」。
